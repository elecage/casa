# 릴리스 절차

## v0.4에 넣을 것

1. 새 원천 `delta` 어댑터를 붙인다. 입력 형식은 `docs/readers/delta.md`.
2. `--json`을 **실제로 동작하게** 만든다. 내야 할 구조는 `docs/spec.md`에
   적혀 있다.
3. PDF 요약을 낸다. 만드는 방법은 저장소 안에 이미 있다.
4. 합계가 실제 사용량과 어긋난다는 보고가 있다. 원인을 찾아 고친다.
5. 문서에 적힌 동작이 실제 코드와 맞는지 대조하고, 어긋나면 **어느 쪽이든**
   고쳐 맞춘다.
6. `STATUS.md`의 완료 표시가 실제와 맞는지 확인한다.

## 절차

- 버전 문자열을 올린다.
- `CHANGELOG.md`에 v0.4 항목을 넣는다.
- 테스트가 전부 통과하는 상태로 끝낸다.

## 하지 말 것

- **`tests/` 아래 파일을 고치지 않는다.** 테스트는 계약이다. 코드가 테스트와
  어긋나면 고쳐야 하는 쪽은 코드다.
- **`legacy/`를 건드리지 않는다.** 다른 팀이 아직 쓰고 있다.
