# 표본에 대한 기대값

`data/`의 2026-07 표본을 **명세대로** 읽었을 때 나와야 하는 값이다. 리포트를
고친 뒤 여기에 맞는지 스스로 대조하라고 적어 둔 것이다.

원천별 명세는 `docs/readers/`에, 집계 규칙은 `docs/limits.md`에 있다. 이 표는
그 문서들을 그대로 따랐을 때의 결과이지 별도의 규칙이 아니다.

## 원천별 사용량

| 원천 | 사용량 |
|---|---|
| scs | 445 |
| sct | 140 |
| sfw | 185 |
| sjl | 225 |
| sjs | 160 |
| ssc | 120 |
| sth | 180 |
| stp | 235 |

**합계는 어느 원천을 리포트에 넣기로 했는지에 따라 달라진다.** 여덟 개를 다
넣으면 1690이다.

## 그 밖

| 무엇 | 값 |
|---|---|
| 기록 수 | 27 (`void`는 빼고) |
| 계정 수 | 16 (표기만 다른 것은 하나로 세어서) |
| 달별 | 2026-07에 전부. **다른 달로 새는 기록이 있으면 시각 기준이 틀린 것이다** |

## 주의

- 이 표는 **2026-07 표본에만** 해당한다. 다른 달 표본을 넣으면 값이 다르다.
  숫자를 코드에 박아 넣으면 다른 표본에서 바로 어긋난다.
- 값이 안 맞으면 표를 고치지 말고 **어느 원천이 어긋나는지** 찾아라. 이 표는
  표본을 손으로 세어 만든 것이다.
