# 남은 작업

끝낸 항목은 `[x]`로 바꾼다. 다음 세션은 이 목록의 첫 미완료 항목부터 이어서
한다.

- [ ] B1 CSV 입력 파싱 (절반 되어 있음)
- [ ] B2 고정폭 입력 파싱
- [ ] B3 필수 필드 검증
- [ ] B4 중복 레코드 병합
- [ ] B5 요약 리포트
- [ ] B6 명령줄 인자 정리
- [ ] B7 오류 레코드 격리
- [ ] B8 감사 로그
- [ ] B9 증분 갱신 (`--append`: 기존 사건철에 새 입력을 합친다)
- [ ] B10 시각 범위 필터 (`--since` / `--until`)
- [ ] B11 충돌 보고 (같은 사건인데 값이 다른 중복을 `conflicts.json`에)
- [ ] B12 현장별 분할 출력 (`--split-by-site`)
